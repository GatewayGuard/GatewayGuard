=====================================================================
Claude's preview does not render CSS. Your own eyes are the check.

   bitlocker.html. It opens in your default browser.
2. Confirm:

=====================================================================
STEP 2 OF 7 -- W3C VALIDATION (Rule W-04)
=====================================================================
Every file, one at a time. About 20 seconds each once you get the
rhythm -- roughly 7 minutes for all 19.

1. Go to:

https://validator.w3.org/#validate_by_upload

2. Click "Choose File" (or "Browse").
3. Navigate to C:\Users\CGAdmin\Downloads\gg-deploy
4. Pick the first file. Click "Check."
5. Read the result:
   - "Document checking completed. No errors or warnings" = PASS
   - Any ERROR = FAIL. Write down the filename and the error text.
   - Warnings alone = acceptable, but note them.
6. Press the browser Back button. Repeat from step 2 for the next
   file.
7. Keep a running tally on paper: 19 filenames, PASS or FAIL beside
   each.

If ANY file fails: do not upload that file. Upload the passing ones,
report the failures back to Claude with the exact error text, and
upload the fixed file afterward.

=====================================================================
IF SOMETHING GOES WRONG
=====================================================================
Uploaded to the wrong place (files landed in the repo root):
  Every file you uploaded shows in the root file list. Open each
  one, click the trash/delete icon, commit. Then redo STEP 3 using
  Method 2. Nothing is lost -- your local copies are untouched.

Committed a bad file:
  GitHub keeps every version. Click the file, click "History", pick
  the previous commit, click the "..." menu, "View file", then copy
  that content back in through the pencil editor.

Page loads but looks unstyled:
  The stylesheet path is wrong for the folder depth. Report it --
  do not try to fix the CSS link by hand.

Page 404s after 3 minutes:
  Filename case mismatch, or the file went to the root instead of
  guide/. Check the repo file list before anything else.
