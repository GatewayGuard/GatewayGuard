### 1. Products Covered

This agreement covers every product GatewayGuard LLC sells. Today that is two products, each with its own terms. If we release further products, this agreement covers those too, and we will say in the product’s own description which sections apply to it.

**GatewayGuard Checkup (“Checkup”):** the Windows 11 security review program, delivered as a PowerShell script together with the small starter file that runs it for you. Covered in Sections 2 through 4.

Buying one product does not give you a license to the other. A bundle purchase covers both.

**What comes with each product.** Your Checkup license covers the script, the starter file that launches it, and any correction we issue for that same version. Your Guide license covers the one print size you chose when you bought. The five sizes differ only in the size of the type. If the size you chose does not suit you, write to us at support@gatewayguard.co and we will send you a different one at no charge.

**Your log file is yours.** Checkup writes a record of what it found and what you approved to a file on your own computer. That file belongs to you. It is never sent to us, and we cannot read it unless you choose to send it. If you contact us for help, we may ask you to send it to us if we think it will help us answer your question — that is your choice each time.

You are buying a license to use Checkup — not Checkup itself. GatewayGuard LLC owns Checkup and holds the copyright in it, including all code, text, and design.

**The PC you install it on.** Your license covers one (1) personal computer that you own or control. The first time you run Checkup, it makes a note of the computer it is running on, and your license belongs to that computer. Nothing about you goes into that note — not your name, not your email, not an account. It only identifies the machine.

> **DECISION NEEDED — for Bill and Claude Code, not the attorney.** Bill's typed note asks for a sentence such as *"the Checkup program will only run on that computer from that point on."* ***Measured on ascii43 (Claude Code, 2026-08-25): Checkup computes a machine identifier and displays it, but never compares it to anything.*** It runs on any PC, every time. **A sentence saying the software refuses to run elsewhere would be a false statement of software behaviour in a consumer contract**, which is the Tamper Protection lesson. If your version of Checkup is a year or more behind the current Windows 11 release, we may suggest the annual update instead, because it will suit the new PC better; that is a suggestion, and the move is still free.

**If you bought a multi-PC pack.** A 3-PC, 5-PC, or 10-PC pack covers that many Windows PCs that you own. Each one is noted separately, the same way, one license per machine, and the same free move applies to each.

**You may read the source code.** Checkup is delivered as a PowerShell script (a .ps1 file). The source code is fully readable in any text editor. We want you to be able to see exactly what Checkup does — that is part of how you know you can trust it. Open it, read it, and inspect it as much as you like.

**Which version your license covers.** Your license covers the version of Checkup you bought. You can run it as many times as you want.

**Fixes to your version.** If we issue a correction to the version you bought — a fix for a defect, not a new annual version — you are licensed to run it, at no charge.

**The yearly Windows update, and the Checkup annual update.** Microsoft releases a major Windows 11 update most years, and it may change or reset security settings. When that happens we offer an **annual update** of Checkup that keeps pace with the changes. The annual update is a separate product and a separate purchase, and it is entirely optional — skipping it does not affect the version you already own. Current prices and terms are listed at gatewayguard.co.
