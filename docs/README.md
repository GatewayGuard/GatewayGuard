# GatewayGuard

Windows 11 security hardening tool for non-technical home users.

This is a scaffold folder structure — content has not yet been migrated
from the working project.

## Layout

- `src/` — PowerShell scripts and modules
  - `core/` — core hardening functions
  - `gui/` — GUI scripts
  - `modules/` — PowerShell modules (`.psm1` / `.psd1`)
  - `build/` — build scripts
  - `utils/` — helper functions
- `tool/` — active PowerShell tooling
- `tool2/` — Python tooling
- `docs/` — documentation
  - `security-guide/` — the Windows 11 hardening guide
  - `architecture/` — diagrams, design notes
- `tests/` — screenshots, logs, test results
- `notes/` — remaining notes or scratch files
