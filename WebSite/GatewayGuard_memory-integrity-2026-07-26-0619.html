Memory Integrity (explained fully below)

There is one part of Windows that controls everything else on your PC. Memory Integrity keeps that part in a locked file location where other programs cannot reach it. Windows calls this setting Core isolation.

✓ GatewayGuard can turn this on for you

What GatewayGuard found and did

Found:Whether Memory Integrity was already switched on.
Action taken:If it was off and your PC can run it, GatewayGuard turned it on. Memory Integrity does not start working until you restart your PC.

Why this matters

One part of Windows controls everything else. Every program you run sits on top of it. If malware reaches that part, it is running underneath your antivirus — which makes it very hard to find and very hard to remove.

Memory Integrity puts that part in a locked file location. Other programs cannot get into it, so malware cannot get into it either.

This closes one of the last remaining ways for an attacker to take over a Windows PC completely. It is worth having on.

How to check it yourself

  1. Press the Windows key and type Windows Security, then open it.
  2. Click Device security in the list on the left.
  3. Under Core isolation, click Core isolation details.
  4. Look at the Memory integrity switch. It should say On. If it does not, turn it on — click the switch, then restart your PC when Windows asks.

Here is the full path. Use the Copy button if you would rather paste it than type it:

Windows Security > Device security > Core isolation details > Memory integrity

When to turn it on yourself

Turn it on yourself in any of these cases:

  1. You checked using the steps above and it says Off.
  2. GatewayGuard could not turn it on because it was not run as an administrator.
  3. It was blocked by a driver before, and you have since updated that driver. See the next section.

You do not need to run GatewayGuard again to do this. The four steps above are all it takes.

If Windows says a driver is blocking it

Leave it Off — forcing it can stop your PC from starting. Windows will name the driver that is blocking it. This is not a fault in your PC. It means one program on it uses an out-of-date driver, and that driver has not been updated to work with Memory Integrity yet.

A driver is the small program that lets Windows talk to a piece of your hardware — your printer, your screen, your network. Updating one is straightforward. Try these in order:

  1. Check Windows Update first. Press the Windows key, type Windows Update, open it, then click Advanced options, then Optional updates. Driver updates often wait there. Install anything listed and restart.
  2. Then try Device Manager. Press the Windows key, type Device Manager, and open it. Find the device Windows named, right-click it, choose Update driver, then Search automatically for drivers.
  3. Then try the maker’s website. Search for the device name plus the word driver. Download only from the manufacturer’s own site — never from a search advert or a “driver updater” program.
Windows Update > Advanced options > Optional updates
What if there is no updated driver? This happens, usually with older hardware or a program the maker no longer supports. You have three choices, and none of them puts your PC at risk:

1. Leave Memory Integrity off and carry on. This is a perfectly reasonable outcome. Everything else GatewayGuard set up still protects you. Memory Integrity is one layer among many, not the only one.

2. Check again in a few months. Makers do release updates later. Repeat the four check steps above now and then.

3. If the program is one you no longer use, remove it. Press the Windows key, type Installed apps, find it, and uninstall it. Once its driver is gone, try turning Memory Integrity on again. Only do this for a program you are sure you do not need.
If you use antivirus other than Microsoft Defender, that is a common cause of this. If Windows reports driver problems after the restart, turn Memory Integrity back off using the same four steps, and try again once that program has been updated.

How to undo it

Follow the same four steps and set Memory integrity to Off, then restart. Nothing is deleted and none of your files are affected, either way.

What to expect after

You must restart. Until you do, nothing has changed.

You may notice two new entries in Task Manager. Memory Integrity is what creates vmmem and vmwp, which together use about 150–300 MB of memory. That is expected and it is doing its job. Leave them alone — do not try to end them.

Everything else should feel the same. On most PCs there is no difference in speed for day-to-day use.
