Save both files to the same folder. Create a folder called GatewayGuard on your Desktop and save both files there. The .bat launcher will not find the .ps1 file if they are in different locations.

Windows may show an unrecognized publisher warning. This is expected for a new, independent security program. Checkup is fully auditable — the source code is the .ps1 file itself. Open it in Notepad and read every line before running it if you want to verify exactly what it does. A code-signing certificate is in progress and will remove this warning in a future release.

How to run it

  1. Save both files to the same folder — for example, Desktop\GatewayGuard.
  2. Double-click Run-GatewayGuard.bat.
  3. Click Yes when Windows asks for administrator access. Checkup needs this to read your security settings — it does not use that access to make any change without asking you first.
  4. Follow the prompts. Checkup reviews each setting, tells you what it found, and asks your permission before changing anything.
  5. When finished, a complete plain-English log is saved to C:\GatewayGuard\Logs\ so you have a record of what was checked and what was changed with your approval.
