Windows Update

Keeps your PC current with the latest security fixes from Microsoft. Most attacks target known security holes — holes Microsoft has already patched. Staying updated closes them.

✓ Checkup can do this for you

What Checkup found and did

Found: Checkup reviews Windows Update and its automatic update settings, including updates for other Microsoft products. It can turn automatic updates back on with your permission.
Action taken: If Windows Update was disabled or set to manual-only, Checkup flagged it and walked you through re-enabling it. No changes are made without your approval.

Why this matters

Hackers look for PCs that haven’t been updated. When Microsoft finds a security hole in Windows, they release a patch. The moment that patch is public, attackers know exactly what the hole is — and start scanning for PCs that haven’t installed the fix yet.

Keeping Windows Update on is one of the simplest and most effective things you can do. It costs you nothing and protects you automatically in the background.

How to check it yourself

  1. Press the Windows key on your keyboard (the key with the Windows logo), then type Windows Update and press Enter.
  2. The Windows Update page opens. Click Check for updates. Windows will look for anything new and download it automatically.
  3. Scroll down and click Advanced options. Make sure these three toggles are turned On:

    • Receive updates for other Microsoft products — covers Office, Edge, and other Microsoft software
    • Download updates over metered connections — optional, but recommended if you’re on a fast home connection
    • Notify me when a restart is required to finish updating — so Windows doesn’t restart at a bad time
  4. Go back to the main Windows Update page. If updates are listed, let them download and install. Click Restart now if prompted — the restart is what completes the installation.
What version of Windows 11 are you on? To check: on the Windows Update page, scroll down and look for Windows 11, version 24H2 (or higher). If you see an older version, click Check for updates and let it install the latest. Windows 10 reaches its end of support on October 14, 2025 — if your PC still runs Windows 10, it will no longer receive security updates after that date.

How to turn it back on if it’s off

  1. Press Windows + R on your keyboard. A small “Run” box appears.
  2. Type services.msc and press Enter. A list of Windows services opens.
  3. Scroll down to find Windows Update. Right-click it and choose Properties.
  4. Under Startup type, change the setting from Disabled or Manual to Automatic. Click Apply, then OK.
  5. Right-click Windows Update again and choose Start. Then go back to Settings › Windows Update and click Check for updates.

What to expect after updating

Most updates install quietly in the background. Some require a restart to take effect — Windows will tell you when. The restart usually takes 5–10 minutes. Your files and settings are not affected. After the restart, Windows is protected against the latest known security threats.

Updates feel slow? That’s normal the first time if your PC has been off for a while. It’s downloading several months of patches at once. After that, updates are small and fast.
