SmartScreen

SmartScreen checks files you download and websites you visit against a constantly updated list of known threats. It’s the warning that appears when you try to run something Microsoft doesn’t recognize — and the block that stops known-bad sites before they load.

Why this matters

Malware usually arrives disguised as something normal — a free program, a PDF, a link in an email. It very often comes from a search result for a free tool. SmartScreen checks what you’re about to open or visit against Microsoft’s threat database before anything runs.

It has three separate layers: one for apps and files you download, one for websites you visit in Edge, and one that warns you when a site asks for your Microsoft account password. All three should be on.

How to check it yourself

  1. Press the Windows key and type Windows Security, then press Enter.
  2. Click App & browser control.
  3. Click Reputation-based protection settings.
  4. Confirm all of the following are set to On: Check apps and files, SmartScreen for Microsoft Edge, Potentially unwanted app blocking, and SmartScreen for Microsoft Store apps.
  5. Scroll down to Phishing protection. Confirm all three sub-options are On: Warn me about malicious apps and sites, Warn me about password reuse, and Warn me about unsafe password storage.

How to change it yourself

  1. Open Windows Security > App & browser control > Reputation-based protection settings.
  2. Toggle any items that are off to On.
  3. No restart required.

What to expect

SmartScreen works in the background. You’ll only see it if you try to download or run something it doesn’t recognize — in which case it shows a warning screen. You can still choose to run the file if you trust it; SmartScreen just makes sure you saw the warning first.

SmartScreen shows a warning on a file I downloaded. Read the warning carefully. If you downloaded the file from a well-known source (the software company’s own website, for example) and you were expecting it, you can choose to run it anyway. If you’re not sure, don’t run it.
