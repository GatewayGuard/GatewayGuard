GatewayGuard Windows 11 Security Guide
Part 1: Getting Started
Welcome

Thank you for choosing GatewayGuard.

This guide works together with GatewayGuard Checkup to help you improve the security of your Windows 11 computer. Every recommendation in this guide is designed for home users and personal computers.

You do not need to be a computer expert to use this guide.

Most settings can be changed with a few mouse clicks. Others are simply reviewed so you can make an informed decision.

Who This Guide Is For

This guide is intended for:

Personal Windows 11 computers
Home users
Families
Seniors
Small home offices

This guide is not intended for:

Employer-owned computers
School-managed computers
Domain-managed computers
Corporate IT environments

If your computer is managed by an employer, school, or government organization, contact your IT department before making changes.

What GatewayGuard Checkup Does

GatewayGuard Checkup examines important Windows security settings and compares them against GatewayGuard recommendations.

Depending on the setting, Checkup will:

Verify the current configuration
Recommend a safer setting
Offer to make approved changes
Provide manual instructions when Windows requires user action

Some Windows features can be changed automatically.

Others require you to complete the change yourself.

When a manual step is required, Checkup explains exactly what to do.

What GatewayGuard Checkup Does Not Do

Checkup is not an antivirus program.

It does not:

Remove malware automatically
Replace Microsoft Defender
Replace a password manager
Manage your online accounts
Change anything without your approval

The purpose of Checkup is to help you improve configuration and security settings that are often overlooked.

Before You Begin

For best results:

Sign in using your normal Windows account.
Connect to the Internet.
Install all available Windows updates.
Save and close open work.
Plug laptops into AC power before making major security changes.
Run Checkup as Administrator when possible.
Understanding Recommendations

Throughout this guide you will see recommendations such as:

Recommended

This is the setting GatewayGuard believes provides the best balance of security, practicality, and ease of use for most home users.

Optional

The setting may improve privacy, convenience, or performance, but reasonable people may choose differently.

Not Recommended

The setting may increase security risks or reduce protections that are otherwise available.

How to Use This Guide

Each setting in this guide follows the same format:

What It Is

A plain-language explanation of the setting.

Why It Matters

How the setting affects security, privacy, or convenience.

GatewayGuard Recommendation

The setting recommended for most home users.

How to Check

Where to find the setting.

How to Change It

Step-by-step instructions.

What To Expect

Any restart, delay, or side effect.

When You Might Choose Differently

Situations where another choice may make sense.

A Note About Security and Convenience

No security guide can make decisions for you.

Some recommendations improve security but reduce convenience.

Others improve privacy but may affect product features.

Our goal is not to force a particular configuration. Our goal is to help you understand the choice so you can make the decision that is right for your situation.
