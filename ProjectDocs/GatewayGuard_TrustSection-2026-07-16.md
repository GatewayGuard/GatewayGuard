## What is GatewayGuard?

GatewayGuard is a fully auditable tool that turns on the powerful
security features already built into Windows 11 Home and Pro. It is
not an antivirus program, and it does not replace one. It does not
slow down your computer, cause lag, or use telemetry -- the automated
collecting and sending of your data to someone else's servers.
Instead of installing mysterious hidden software, it simply sets up
the professional-grade protections Windows already includes -- and
explains every change in plain English.

## Why IT Professionals Trust It

GatewayGuard earns trust with facts, not marketing claims:

**Zero-bloat design.** It acts only as a setup tool for built-in
Windows security features. When it finishes, it shuts off completely.
It leaves nothing running in the background and uses none of your
computer's memory afterward.

**Total code transparency.** The entire program is written in plain,
readable text scripts. Anyone -- from everyday users to security
experts -- can open it in Notepad and read line by line exactly what
it changes before running it.

**You are in control.** It never makes major changes or restarts your
computer without warning. For big actions (like a deep boot-time
scan), it stops and asks your permission first, so you never lose
open work.

**Plays well with other software.** It doesn't try to replace your
current protection. If it detects other security tools (like
Malwarebytes), it adjusts to work alongside them.

## GatewayGuard vs. Paid Antivirus Suites

| Feature | GatewayGuard | Typical Paid Antivirus Suite |
|---|---|---|
| Can you see the code? | 100% auditable -- plain text anyone can read, line by line | Hidden -- locked in program files you aren't allowed to inspect |
| Impact on your PC | Runs only while changing a setting, then shuts off completely | Runs constantly in the background, using processor and memory |
| How it protects you | Strengthens the defenses Windows already includes | Adds its own separate scanning engines on top of Windows |
| Your privacy | Sends nothing over the internet. Never tracks your behavior | Many collect usage data and send it to their own servers |
