-- SETTING both values to 30 pixels ----------------------------------

  What this means in plain terms:
  You will have to move the mouse 30 pixels -- about 7.9 mm on a
  standard-density screen -- with the button held down before Windows
  starts dragging anything. A normal click, and a small twitch during
  a click, will no longer move a folder.

  Deliberate drag-and-drop still works. It just needs to look
  deliberate.

-- AFTER --------------------------------------------------------------
  DragHeight : 30
  DragWidth  : 30

  WRITTEN AND READ BACK. Both values confirmed.

-- ONE MORE STEP, AND IT IS NOT OPTIONAL ------------------------------
  Windows reads these values when you sign in, so nothing changes
  until you SIGN OUT and SIGN BACK IN (or restart the PC).

  Start > your name > Sign out.  Then sign back in and try to nudge a
  folder. It should not move.

-- TO UNDO ------------------------------------------------------------
  Run this again by double-clicking Run-SetDragThreshold-Revert.bat,
  which puts both values back to 4. Sign out and in again afterwards.

-- ALSO WORTH KNOWING -------------------------------------------------
  If a folder ever does move by accident, press Ctrl+Z in File
  Explorer straight away. That undoes the move and puts it back.
