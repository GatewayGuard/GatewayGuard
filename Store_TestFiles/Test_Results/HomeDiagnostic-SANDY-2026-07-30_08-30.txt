J. MEMORY INTEGRITY vs KERNEL DMA PROTECTION (two different things)
====================================================================
  These are SEPARATE features that sit next to each other on the Device
  security page, and confusing them is easy:
    Memory integrity      -- under Core isolation. Section B above.
    Kernel DMA Protection -- its own row. Blocks attacks through external
                             plug-in ports. Often Off, or not shown.
  Read below from msinfo32's own fields -- the same authority the
  BitLocker code already defers to for Device Encryption Support.

  Running msinfo32 (this takes 10-30 seconds)...
    Kernel DMA Protection	Off
    Automatic Device Encryption Support	Meets prerequisites
    Virtualization-based security	Not enabled
    Secure Boot State	On
    BIOS Mode	UEFI
    A hypervisor has been detected   : <not reported by msinfo32>

  COMPARE with Section B. If Memory integrity is ON there but the Device
  security page shows something Off, the Off row is almost certainly
  Kernel DMA Protection -- a different feature, not a Checkup fault.
