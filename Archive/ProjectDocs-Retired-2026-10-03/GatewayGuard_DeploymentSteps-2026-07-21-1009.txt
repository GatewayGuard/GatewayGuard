=====================================================================
REQUIRED PRE-UPLOAD CHECKS -- DO THESE BEFORE TOUCHING GITHUB
=====================================================================
Both checks below are MANDATORY for every file before it goes to
GitHub. Do not skip them. A broken page going live is harder to fix
than catching it here first.

PRE-CHECK A -- Open in browser (Rule W-03)
  Claude's preview does not render CSS. You must open each file in
  Chrome or Edge on your PC and confirm it looks correct with your
  own eyes before uploading.

PRE-CHECK B -- W3C Validation (Rule W-04)
  Go to: https://validator.w3.org
  Click "Validate by Direct Input."
  Open the HTML file in Notepad, copy all content, paste into the
  validator, and click "Check."
  ERRORS must be fixed before the file goes to GitHub.
  Warnings are acceptable; errors are not.
  Do this for EACH file separately.

STEP 1 OF 8 -- Browser check: home page
=====================================================================
1. Find GatewayGuard_index-2026-07-21-0933.html in your Downloads
   folder.
2. Double-click it. It opens in your default browser.
3. Confirm ALL of the following:
   - Nav bar shows: Home | Download | Guide | Tips | Beta | Compatible
   - Hero section shows with heading and two buttons
   - "What GatewayGuard does" section shows 3 cards
   - "How it works" section shows 3 steps
   - "What it does NOT do" section shows 8 bullet items
   - "Tested hardware" table shows 3 machines
   - Download CTA section shows pricing
   - Beta teaser section shows
   - Footer shows "support@gatewayguard.co"
     (NOT william.wfbiii@gmail.com)
4. If anything looks wrong, stop. Do not continue until fixed.

=====================================================================
STEP 2 OF 8 -- W3C validation: home page
=====================================================================
1. Open GatewayGuard_index-2026-07-21-0933.html in Notepad
   (right-click the file --> Open with --> Notepad).
2. Press Ctrl+A, then Ctrl+C to copy all content.
3. Go to: https://validator.w3.org/#validate_by_input
4. Click in the text area, then press Ctrl+V to paste.
5. Click "Check."
6. Result must show: no errors (warnings only are acceptable).
7. If there are ERRORS: stop. Note the error line numbers and
   report back to Claude before continuing.
8. If validation passes: proceed to Step 3.

=====================================================================
STEP 3 OF 8 -- Upload the home page to GitHub
=====================================================================
1. Go to: https://github.com/gatewayguard/gatewayguard.github.io
2. Click on "index.html" in the file list.
3. Click the pencil icon (Edit this file) in the top right.
4. Press Ctrl+A to select all existing content. Delete it.
5. Open GatewayGuard_index-2026-07-21-0933.html in Notepad.
6. Press Ctrl+A to select all, then Ctrl+C to copy.
7. Click back in the GitHub editor window. Press Ctrl+V to paste.
8. Scroll to the bottom of the page.
9. Click "Commit changes..."
10. Leave the default commit message or type:
    "Update home page 2026-07-21"
11. Click "Commit changes" (green button).

NOTE: If the Commit button is unresponsive, press F11 (full screen
toggle), then try again. If still stuck, press Ctrl+Shift+R (hard
refresh) and re-paste. This is a known GitHub online editor quirk.

=====================================================================
STEP 4 OF 8 -- Confirm home page is live
=====================================================================
1. Wait 60 seconds.
2. Go to: https://gatewayguard.co
3. Press Ctrl+Shift+R (hard refresh) to bypass browser cache.
4. Confirm the page loads correctly and the footer shows
   support@gatewayguard.co.
5. If not live after 2 minutes, wait another minute and refresh again.
6. DO NOT proceed to the guide index until the home page is
   confirmed live. (Rule W-05: one file at a time.)
