### WHAT IS GDPR? (for slide 7 discussion)

GDPR stands for General Data Protection Regulation.
It is a European Union law that took effect in 2018.

**What it requires:**
- Any company that collects personal data from EU citizens
  must protect that data, disclose what they collect,
  allow users to request deletion, and report breaches.
- Fines for violations can reach 4% of global annual revenue
  or €20 million -- whichever is higher.
- It applies to ANY company anywhere in the world that
  handles EU citizen data -- not just European companies.

**Why it matters for GatewayGuard:**
GatewayGuard collects ZERO data. It runs offline, creates no account,
sends no telemetry, stores no personal information anywhere.
Because we collect nothing, we have nothing to report, protect, or disclose.
We are GDPR compliant by design -- not by policy.

**Why this is a marketing advantage:**
European users -- especially German users -- are extremely privacy-conscious.
Germany has some of the strictest privacy enforcement in the world.
"Zero data collected. Compliant with GDPR by design, not by policy"
is a headline that resonates deeply in those markets.
It's also credible because it's architecturally true -- we can't
violate GDPR because there's nothing to violate.

### WIFI AND PROGRAM ADVICE DURING TOOL RUN

**Question from notes:** Should users turn off WiFi while running GatewayGuard?

**Answer: No -- but close all other programs.**

Reason not to turn off WiFi:
- GatewayGuard checks Windows Update status -- needs network access
- Scheduled scan setup may need to verify Windows Update service
- BitLocker recovery key verification may need Microsoft account access

**What to tell users instead:**
- Close all other programs before starting GatewayGuard
- Don't browse the web or use other apps during the session
- If Defender or Malwarebytes starts a scan during the session,
  wait for it to finish before continuing
- After the session -- especially after any AV changes -- restart your PC

**Add to tool:** Pre-flight screen should say:
"Please close all other programs now before continuing.
Running GatewayGuard alongside other active programs
may slow the process and cause unexpected results."

**After dealing with Defender/Malwarebytes findings:**
Always restart the PC. AV configuration changes take full effect
after a clean reboot. Add to post-run screen:
"We recommend restarting your PC now to apply all changes."

### LOCAL NON-ADMIN ACCOUNT -- SECURITY AND GATEWAYGUARD

**What is a local non-admin account?**
Windows 11 has two main account types:
- Administrator: full access to change system settings
- Standard User: limited access -- can't install software or
  change security settings without an admin password

**Why some users have non-admin accounts:**
- IT-managed computers at work
- Parents who set up children's accounts as standard users
- Security-conscious users who follow the "least privilege" principle

**Security benefits of running as a standard user:**
Running day-to-day as a standard user (not administrator) is actually
a strong security practice. It means:
- Malware that gets onto your PC can't install itself system-wide
- Ransomware can't encrypt system files
- Accidentally clicking a bad link causes less damage
- Attackers who compromise your account have limited reach

**GatewayGuard and non-admin accounts:**
GatewayGuard requires Administrator rights to check and change
security settings. A standard user CAN run GatewayGuard by:
1. Right-clicking Run-GatewayGuard.bat
2. Selecting "Run as administrator"
3. Entering the Administrator password when prompted

GatewayGuard will then run with full Administrator access
even though the user's normal account is a standard user.
After GatewayGuard finishes, the session returns to normal
standard user access automatically.

**What GatewayGuard will note for non-admin accounts:**
The tool detects if it's running with limited vs full admin access
and adjusts its recommendations accordingly. Some settings
(Group Policy, BitLocker on Pro) require full admin. These will
be flagged as "Requires administrator -- see guide for instructions."

**Recommendation for website write-up:**
Create gatewayguard.co/local-account explaining:
- What standard user accounts are
- Why they're actually good security practice
- How to run GatewayGuard from a standard user account
- What a user misses if they don't have admin access
